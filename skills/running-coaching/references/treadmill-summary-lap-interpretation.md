# Treadmill activity totals versus lap distances

## Evidence pattern

A treadmill import can have one recorded activity-summary distance while the lap distances sum to a different total over exactly the same duration. Compare the actual source totals with tools. Preserve the summary as the imported headline and distinguish it from independently verified physical distance. Explicit user confirmation of the recorded total and absent power is current context, not a reason for repeated investigation.

The failure to avoid is presenting the conflicting lap-derived total/pace as a competing whole-run verdict, or an 'imaginary speed' warning that unnecessarily challenges the accepted total. An internal numerical discrepancy is not sufficient evidence that the runner's total is wrong.

John often adjusts the post-run total to match the treadmill console; use this known workflow as a common explanation, not proof that this specific run was edited.

## Reusable handling

1. Check summary distance, summed lap distance and both durations with tools. Equal durations do not suggest missing run time.
2. Retain the summary as the recorded headline and preserve raw laps. Explicit user confirmation supports acceptance of the recorded total, not a claim of laboratory accuracy.
3. A post-run edit to match the console can leave laps on their pre-adjustment distance scale. Once the user confirms the post-run edit for this run, the mismatch mechanism is explained; do not keep calling it unknown. Without confirmation, a post-run edit remains a hypothesis, not an inferred calibration event. The accepted summary is the recorded headline, not independently verified physical distance. Preserve the adjusted summary and original laps as recorded. Do not infer whether distance came from the treadmill, watch accelerometer, or another sensor merely because Stryd was absent.
4. Qualify repetition pace, distance per effort, PBs and progression against their actual distance source. A diagnostic alternate pace is not a replacement recorded headline; console-adjusted summary pace is not automatically more accurate than original lap pace.
5. Use timed work/recovery counts and appropriately qualified within-bout mechanics. Shorter recorded sprint distances alone do not prove loss of speed when lap calibration is unresolved; stable cadence or rising GCT alone does not settle the cause either.
6. Accept explicitly absent power; do not turn it into an authentication or sensor investigation without conflicting evidence.

## Stryd distance-source priority

When Stryd pace/distance is verified as the original source, prefer it over the treadmill console for physical-distance interpretation absent contrary calibration or sensor evidence. Stryd power presence alone does not establish the pace/distance source. Check actual sensor/watch source evidence; if unavailable, state the uncertainty once, do not invent Stryd-derived laps or default to the console as ground truth.

Never silently rescale laps, overwrite totals, change calibration, reimport, or edit saved notes to resolve this discrepancy. A separately requested correction needs the supported authorization path; a conversational explanation is not write permission. Use validated source-labelled power and duration for execution assessment; qualify pace comparisons, records and progression against the actual distance source. Stable watts do not independently verify distance or calibrated intensity.

Stryd's [Treadmill & Stryd Common Questions](https://help.stryd.com/en/articles/8961322-treadmill-stryd-common-questions) and [Pace & Distance Accuracy](https://help.stryd.com/en/articles/6879062-pace-distance-accuracy-how-to-understand-test-and-fine-tune-stryd-s-pace-distance) are manufacturer guidance, not per-run proof. The user-supplied accepted guidance distinguishes console speed, actual belt speed and runner speed, describes loading-related belt-speed variation, and recommends Stryd pace/distance rather than scaling it to the console. This is a paraphrase of supplied guidance, not a freshly verified quotation or evidence that any particular activity used Stryd distance. Consult the original manufacturer articles for updated guidance; activity-specific source provenance must still be checked independently.

## Concise explanation

When the edit is confirmed: “You adjusted the summary to the treadmill display; laps retain their pre-adjustment scale. That explains the mismatch. The summary remains the recorded total, not independently verified distance.”

When the edit is unconfirmed: “The summary and laps use different distance scales over the same duration. A post-run edit could explain it, but that mechanism is unverified. I will preserve both recorded sources.”

If distance provenance is unknown, add only when material: “If the original pace/distance came from Stryd, it is generally preferable to the console. Stryd power alone does not establish that source.” With verified Stryd pace/distance, name it directly instead of retaining a hypothetical caveat.

A clarification does not itself repair already-saved coaching. Keep conversational correction and persisted-note repair distinct; use an authorized supported repair path if requested, never reimport or silently mutate records to fix prose.
