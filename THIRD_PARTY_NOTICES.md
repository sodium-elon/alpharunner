# Phosphor icons

Selected from [Phosphor Bold on SVG Repo](https://www.svgrepo.com/collection/phosphor-bold-icons/).
SVG geometry is vendored from the original [Phosphor repository](https://github.com/phosphor-icons/core/tree/2b75f3ad12b420c9504ef05df8d2564a28f8500e/assets/bold) at commit `2b75f3ad12b420c9504ef05df8d2564a28f8500e`.
Only the required icons are included. All use the original bold weight, 256-unit viewBox, and currentColor.
